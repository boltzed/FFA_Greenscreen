# Green Screen (FFA_Greenscreen)

Map for content creators or people wanting cutouts of their in game character.

## Map features

- In game adjustable day/night time switch
- Weapon wall
- Blue and green screen

## Important key binds

- **Alt + F2** to enter free cam (Nvidia GPU only)
- **togglehud** (console command to get rid of all UI)

## Install

Install through the Unchained launcher, or download `FFA_Greenscreen.pak` from the latest release.

## Source

`Content/Mods` holds the Unreal source assets for the map (ArgonSDK / UE 4.25).
Copy the `Mods` folder into your ArgonSDK project's `Content` folder and open `Mods/FFA_Greenscreen`.
